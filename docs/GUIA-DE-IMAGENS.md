# Uso das imagens

- Acesse arquivos pelo prefixo `/images/` em Next.js; não use `/public/images/` na prop `src`.
- Produto: proporção aproximada quadrada, usar `object-fit: cover` e `object-position: center 45%`.
- Hero: `/images/hero/hero-burger-recorte.webp` é recorte vertical de alimento; o arquivo de campanha com texto deve ser reservado para uso promocional sem texto sobreposto.
- Cardápio: dados em `data/cardapio-demo.json`. Imagens dos combos têm elementos de embalagem/refrigerante gerados artificialmente: tratar como fotografias ilustrativas, não como representação comercial fiel de marcas reais.
- Para garantir coesão, mantenha os ativos existentes até obter novas fotos próprias.
- O kit não inclui vídeos, fotografias de porções e bebidas isoladas nem logo original vetorial exata.
